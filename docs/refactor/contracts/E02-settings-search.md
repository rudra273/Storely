# Settings search

Search from the existing Settings page on web and Store on Android. Match trimmed, case-insensitive literal text against the labels of available sections and task aliases. Selecting a match opens the same section or editor as the existing controls. An empty query returns to ordinary settings navigation. An unmatched query explains that there are no matching settings.

| Task | Web destination | Android destination |
|---|---|---|
| Shop name, address or GSTIN | Shop details | Shop Profile |
| GST scheme, rates or margin | Pricing & tax | Pricing Defaults |
| Low-stock threshold | Shop details | Low-stock alert |
| Invoice layout, logo or footer | Invoice appearance or Logo and signature | Bill Settings |
| Printer or paper size | Printing | App Settings for the receipt printer and Bill Settings for paper size |

Search only settings already available to the current role. Do not index current field values or change any setting when searching. Web tab changes share the existing editor draft. Clear search on workspace changes. Keep platform-specific settings alongside the shared tasks where they are available.
